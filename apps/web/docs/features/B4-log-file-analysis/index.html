B4 · Pillar B

Log File Analysis

Planned v2 (enterprise)

Phase 3

Large sites need to know how crawlers — including AI bots — actually spend crawl budget, and which pages are never reached at all. Log-file analysis is a long-standing enterprise SEO capability; the addition here is treating AI bot traffic as a first-class dimension of it.

What it does

  • Crawl budget analysis from raw server logs
  • AI bot traffic broken out separately
  • Orphaned and never-crawled page detection
