B1 · Pillar B

Technical Audit

Shipped MVP

Rule engine + Playwright crawler

Crawl the site, find what is technically wrong, and — the part that matters — emit findings that can actually be executed. Alongside standard technical SEO auditing it runs an AI-crawler access audit: whether GPTBot, ClaudeBot and PerplexityBot are even permitted to read you, which is a question classic auditors do not ask and a surprising number of sites fail.

What it does

  • Playwright crawl of the live site
  • Standard technical SEO checks, scored by predicted impact
  • AI-crawler access audit (GPTBot, ClaudeBot, PerplexityBot)
  • Every finding carries the action that would fix it
